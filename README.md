# Face Detection using YOLO Models
Welcome to the Face Detection using YOLO Models repository! This project implements face detection using the YOLO (You Only Look Once) family of deep learning models, offering real-time and efficient face detection.

### Features
Real-time Face Detection: Detects faces in images and video streams with high accuracy.

YOLO Models: Supports multiple versions of YOLO (YOLOv3, YOLOv4, YOLOv5, and YOLOv8).

Optimized Performance: Fast inference speed with minimal computational resources.

Custom Training: Supports training on custom face datasets.

Multiple Input Sources: Works with images, videos, and webcam feeds.

### Prerequisites
Ensure you have the following installed:

Python 3.8+

YOLO Model Weights (for YOLOv5 & YOLOv8)

OpenCV

PyTorch

Ultralytics YOLO (for YOLOv5 & YOLOv8)

### Installation

Clone the Repository:
```bash
git clone https://github.com/yourusername/face-detection-yolo.git
```

Navigate to the Project Directory:
```bash
cd face-detection-yolo
```

Install Dependencies:
```bash
pip install -r requirements.txt
```

### Download Pre-trained Weights:

Download YOLO model weights from the official sources/ it automatically download after you run programme.

### Usage
Run Face Detection on an Image/Video/Webcam
```bash
python filename.py
```
